# Issue #13

## Prompt

10000 foot view: what's the real correct answer to these issues? boundary_ray being rescaled is a kludge and mistreats aberrations. i don't want to only track non-clocked rays and have piece-wise functions or results which depend on the number of rays I started with. would back-propagation of rays from the aperture edge be an option, or do you have other suggestions?

## Response

The correct answer is to stop asking one finite ray array to represent three different things:

1. Individual physical trajectories.
2. Beam-current integration.
3. The continuous boundary of the transmitted beam.

Those require separate numerical treatments.

### A better model

Represent every initial ray by a point in source phase space:

\[
q=(x_0,y_0,\theta_{x0},\theta_{y0},E)
\]

Propagation defines a map \(T_z(q)\). An aperture adds a constraint:

\[
x_a(q)^2+y_a(q)^2 \le r_a^2
\]

After multiple apertures, the transmitted beam is the set of initial states satisfying every aperture constraint. Rays should never be geometrically rescaled at an aperture; they either belong to that set or they do not.

Then calculate different quantities appropriately:

- **Current:** integrate the source density over the transmitted phase-space set.
- **Convergence angle:** optimize or statistically measure the angles over that transmitted set.
- **Marginal-ray focus:** propagate actual rays on the boundary of that set.
- **Best focus:** minimize a weighted beam-width measure over \(z\), usually RMS or a percentile radius.

### Back-propagation

Back-propagating from an aperture rim is a good way to find real boundary rays, but the rim position alone does not specify a ray. A ray at the aperture also has two angles, energy, and potentially other source coordinates.

The useful formulation is a constrained solve:

\[
x_a(q)^2+y_a(q)^2=r_a^2
\]

subject to:

- \(q\) lies within the source distribution;
- the ray passes every preceding aperture;
- it has the relevant azimuth or extremal downstream property.

You can start with points around the aperture rim, back-propagate them to generate candidate source states, and then refine those candidates with a root finder. Once found, propagate those real rays normally through downstream aberrations. Do not rescale their position or angle.

For multiple apertures, the transmitted boundary can contain pieces generated by:

- the source boundary;
- aperture 1’s rim;
- aperture 2’s rim;
- intersections between multiple active constraints.

Consequently, back-propagating only from the last aperture can miss the actual limiting rays.

### Recommended rayTEM architecture

I would separate the calculation into three layers:

- `Rays`: ordinary physical trajectories and their quadrature weights. Apertures only mask weights.
- `BeamDistribution`: the continuous source density and all accumulated aperture constraints.
- `BeamBoundary` or `MarginalRays`: real rays found through constrained solves, with their original source coordinates retained.

`boundary_ray` should therefore not be manufactured by rescaling an existing ray. It should either be removed or replaced by a collection of real marginal rays found from the continuous source model.

For the principal measurements:

```text
I_per_plane
    = integral of source density over all states passing every aperture

convergence_angle_at(z)
    = maximum, percentile, or RMS angle over the transmitted distribution

focus_error
    = best_focus_z - requested_focus_z
```

For an aberrated beam, I recommend defining `best_focus_z` as the plane minimizing a weighted spot-size function:

\[
z_\mathrm{best}
=
\operatorname*{arg\,min}_z
\frac{\int_{\mathrm{transmitted}}\rho(q)\,
\lVert \mathbf{x}(z,q)-\bar{\mathbf{x}}(z)\rVert^2\,dq}
{\int_{\mathrm{transmitted}}\rho(q)\,dq}
\]

This remains meaningful when marginal rays do not share one crossover. A separate `marginal_focus` function can report where opposing aperture-edge rays cross or reach minimum separation.

### Smoothness

A hard aperture creates a genuinely discontinuous decision for an individual ray. No implementation can make every derivative globally smooth when an aperture begins clipping the beam or when the identity of the limiting aperture changes.

However, integrated quantities such as current and RMS radius can be made numerically smooth by using:

- deterministic weighted quadrature instead of counting equal-weight rays;
- adaptive refinement near aperture boundaries;
- soft aperture transmission during optimization, followed by validation with the exact hard aperture;
- derivative-free fitting when transitions between limiting apertures matter.

A sigmoid approximation is often useful during fitting:

\[
T(d)=\frac{1}{1+\exp((d-r)/\epsilon)}
\]

Reduce \(\epsilon\) as the fit converges, then evaluate the final result using the hard aperture.

### Practical recommendation

The best near-term solution is:

1. Stop rescaling `boundary_ray`.
2. Keep masked rays and weights for plotting and approximate integration.
3. Implement a deterministic source quadrature so results converge predictably.
4. Find real marginal rays with constrained root solving, using aperture-rim back-propagation as an initial guess.
5. Define `focus_error` from minimum weighted RMS beam radius.
6. Retain marginal-ray crossover as a separate diagnostic.

For an axially symmetric microscope, this can initially be reduced to a small radial phase-space problem and should be quite manageable. A fully general astigmatic or misaligned system requires a boundary in four-dimensional transverse phase space; there is no single “outer ray” that accurately represents it.
